# LabWarden — Logo Guidelines

## 1. The logo
**Idea:** a watchtower built from three server units, with one unit showing an orange warning light. The tower stands for "Warden", the rack stands for "Lab", and the orange diamond is LabWarden's job: pointing at the one host that needs attention.

| Version | File | Use it for |
|---|---|---|
| Horizontal (primary) | `masters/labwarden-horizontal-color.svg` | Website header, README, docs |
| Stacked | `masters/labwarden-stacked-color.svg` | Square spaces, splash screens, stickers |
| Symbol | `masters/labwarden-symbol-color.svg` | Avatars, UI corner mark, 48 px and up |
| Small cut | `masters/labwarden-symbol-small-color.svg` | Favicon and anything 32 px or smaller |
| Wordmark | `masters/labwarden-wordmark-color.svg` | When the symbol already appears nearby |
| App icon | `masters/labwarden-app-icon.svg` | PWA/home screen (rendered into `web/public/`) |

Every version also comes as `-reversed` (for dark backgrounds) and in one colour (`exports/one-colour/`: black, white, orange).

## 2. Clear space
Leave at least **one server unit's height** of empty space on every side. That is the height of one of the three bars, about 22 % of the symbol's height. The space grows and shrinks with the logo.

## 3. Minimum size
| Version | Screen | Print |
|---|---|---|
| Horizontal | 120 px wide | 30 mm wide |
| Stacked | 64 px wide | 16 mm wide |
| Symbol | 48 px. Below that, use the **small cut** (good down to 16 px) | 6 mm |

## 4. Colour
| Name | Role | HEX | RGB | CMYK (approx.) | Pantone (nearest) |
|---|---|---|---|---|---|
| Ink | Tower, wordmark, dark backgrounds | `#111418` | 17 20 24 | 70 60 50 90 | Black 6 C |
| Signal | The alert light, and nothing else | `#FF5A1F` | 255 90 31 | 0 75 90 0 | 1655 C |
| Slate | UI secondary text | `#5B6573` | 91 101 115 | 60 45 35 15 | 431 C |
| Paper | Light backgrounds | `#F4F2EE` | 244 242 238 | 3 3 5 0 | 9224 C |

The CMYK and Pantone values are starting points. Check them against a printed swatch before any print run.

**Contrast:** Ink on white is 18.5:1. Signal is 3.1:1 on white and 5.9:1 on Ink. Signal is fine for graphics and large text, but don't use it for body text on white. Slate on white is 5.9:1, which passes for text.

**Approved pairs:**
- full colour on white or Paper
- reversed (white + Signal) on Ink
- black on white
- white on any dark photo or colour

Keep Signal for the alert light only. Don't colour the tower orange. Signal pairs naturally with the product UI: use the same diamond as the marker for critical and KEV findings.

## 5. Typography
- **Wordmark:** custom squared capitals, drawn as outlines (no font needed and no font licence involved). "LAB" is set lighter and "WARDEN" heavier, so the compound name reads even in one colour. Never retype it in a font.
- **Suggested UI fonts (all open licence, OFL):** Inter for interface and docs, JetBrains Mono for code, CVE IDs and logs.

## 6. Don'ts
- Don't stretch, squash, rotate or skew the logo.
- Don't recolour outside the palette, and don't make the tower orange.
- Don't move the diamond to another unit, add more diamonds, or animate it in a way that changes the shape.
- Don't add shadows, outlines, gradients or glows.
- Don't rearrange or resize the parts of a lockup.
- Don't use the detailed symbol below 48 px. Use the small cut instead.
- Don't put the full-colour version on busy or mid-tone backgrounds. Use the one-colour or reversed version.

## 7. Files
- `masters/`: master SVGs (paths only, no live text, no effects)
- `exports/one-colour/`: black, white and orange one-colour SVGs
- `exports/png/`: full-colour PNGs for slides and documents
- `src/`: Python scripts (standard library only) that regenerate every SVG in `masters/` from exact geometry. They write only to `masters/`. Run them in a container from the repo root:

  ```bash
  docker run --rm -v "$PWD/docs/brand:/brand" -w /brand/src \
    python:3.13-alpine@sha256:1e1f6334529d1fb26a2ef619d7cffb30a7c7d7cc1cc7338ebee283a58d1aeaca \
    sh -c "python3 build.py && python3 icons.py"
  ```

  The one-colour SVGs, PNGs and web icons are not regenerated by these scripts.

### Copies used by the dashboard
The web build can't read `docs/`, so the dashboard keeps its own copies. After changing a master, copy it over as well:
- `web/public/`: `favicon.ico`, `favicon.svg` (the small cut, switches to white in dark mode), `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `manifest.json`
- `web/src/assets/brand/`: the horizontal lockup and the symbol, colour and reversed, used in the sidebar and on the login page
- `web/src/components/Brand.tsx`: the small cut, drawn inline as `BrandMark` for the collapsed sidebar

## 8. Product UI
The dashboard uses the same palette as the logo. The tokens live in `web/src/theme.ts`; pages use the tokens, never the hex values.

**Surfaces**

| Token | Light | Dark | Use it for |
|---|---|---|---|
| `canvas` | Paper | `#0A0C0F` | The ground: sidebar, top bar, login page |
| `surface` | White | Ink | The content sheet, cards, side sheets |
| `gray.solid` | Ink | White | Primary buttons and the selected state |
| `fg.muted` | Slate | gray.400 | Secondary text |

- The sidebar and the top bar sit on the canvas, with no border. The page is one rounded `surface` sheet on top of it.
- Corners: controls 8 px (`l2`), cards 12 px (`l3`), the content sheet and side sheets 16 px (`sheet`).
- Shadows are for things that float: side sheets use `overlay`. Cards, tables and the content sheet stay flat, with a hairline border.
- Tables have no frame. The header is a tinted band of small uppercase labels. Short lists (Overview, Hosts) use the comfortable size, long ones (findings, scans, logs) the dense size.

**Colour**

- The accent is Ink. No gradients and no second accent colour. Links stay blue so they read as links.
- **Signal is the alert light, here too.** It appears in the logo and as the diamond that marks a known-exploited (KEV) finding, and nowhere else. Buttons, badges and charts never use it, and no other orange stands in for it: "needs a look" is yellow.
- Severity has its own fixed colours (`sev.*`). They always come with a text label.
- A selected item never relies on colour alone: it also gets a border, a heavier weight or a check mark.
- `fg.subtle` is for decoration (a dash in an empty cell, a zero count). Text that someone needs to read uses `fg` or `fg.muted`.

**Logo in the dashboard**

- Expanded sidebar: the horizontal lockup (`BrandLockup`), at least 120 px wide.
- Login page: the detailed symbol (`BrandSymbol`), 48 px or larger.
- Collapsed sidebar: the small cut (`BrandMark`), because the rail is narrower than 48 px.
- Never set the name in a font next to the symbol.

**Sheets and dialogs**

- A task with a form opens in a side sheet (`Sheet`): adding a host or a registry image, editing a host, triage. The sheet floats in from the right with a gap to the window edge and takes the full width on a phone. Its footer stays in view: what will happen on the left, the buttons on the right.
- An open sheet is part of the URL (`?sheet=…`), so Back closes it and a link can open it.
- Confirming something destructive (deleting a host, revoking a token) stays a centered alert dialog.

**Checking a change.** `scripts/screenshots.sh` renders every page in light and dark at three widths into `screenshots/` (not committed). Look at both modes before opening a pull request.
